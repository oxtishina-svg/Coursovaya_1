# Курсовая работа: анализ банковских транзакций

Приложение для анализа банковских транзакций из Excel-файла.

Проект реализует обработку данных о банковских операциях, формирование JSON-ответов для веб-страницы, поиск по транзакциям, создание отчетов и получение данных о валютах и акциях через внешние API.

## Реализованный функционал

В рамках курсовой работы реализованы задачи из трех обязательных категорий.

### Веб-страница «Главная»

Функция формирует JSON-ответ с информацией:

- приветствие в зависимости от времени суток;
- информация по банковским картам:
  - последние 4 цифры карты;
  - сумма расходов;
  - рассчитанный кешбэк;
- топ-5 транзакций по сумме платежа;
- курсы валют из пользовательских настроек;
- текущая стоимость акций из пользовательских настроек.

Для анализа используются транзакции с начала месяца до переданной даты.

### Сервис «Простой поиск»

Сервис выполняет поиск по транзакциям:

- по категории;
- по описанию;
- по подстроке;
- без учета регистра.

Результат возвращается в формате JSON.

### Отчет «Траты по категории»

Отчет позволяет получить расходы по выбранной категории за последние три месяца относительно указанной даты.

Реализован декоратор для автоматического сохранения отчетов в Excel-файл.

Декоратор поддерживает:

- имя файла по умолчанию;
- пользовательское имя файла.

## Установка

Для управления зависимостями используется Poetry.

Установите зависимости проекта:

```bash
poetry install
```

Если Poetry не доступен через PATH в Windows:

```powershell
& "$env:APPDATA\Python\Scripts\poetry.exe" install
```

## Пользовательские настройки

В файле `user_settings.json` задаются валюты и акции, которые будут отображаться на странице «Главная».

Пример:

```json
{
  "user_currencies": [
    "USD",
    "EUR"
  ],
  "user_stocks": [
    "AAPL",
    "AMZN",
    "GOOGL",
    "MSFT",
    "TSLA"
  ]
}
```

## Тестирование

Запуск всех тестов:

```bash
pytest
```

Запуск тестов с подробным выводом:

```bash
pytest -v
```

Проверка покрытия кода тестами:

```bash
pytest --cov=src --cov-report=term-missing
```
